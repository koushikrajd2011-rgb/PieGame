PieGame -

It is based on Pies.
Collect the pies using the basket at the bottom using left and right arrow buttons. Get a high score, you only have 3 lives.

Do not collect the explosion in your basket, dodge it or you lose a life.

Download the game here - https://github.com/koushikrajd2011-rgb/PieGame/releases/tag/v1.0.0
